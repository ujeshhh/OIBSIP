# 🌟 Oasis Infobyte Internship Projects

Welcome to my internship project repository for **Oasis Infobyte**!  
Over the course of this internship, I worked on a series of hands-on tasks that helped me sharpen my skills in **Data Science**, **Machine Learning**, and **Data Visualization**.

---

## 📌 Tasks Overview

### 🚀 Task 1: **Landing Page Web Design**
- Developed a responsive and modern landing page using HTML, CSS, and JavaScript.
- Applied design principles to create an engaging and user-friendly layout.
- Ensured cross-device compatibility and smooth UI transitions.
---

### 📊 Task 2: **Unemployment Analysis in India**
- Analyzed real-world unemployment data using Python.
- Cleaned and preprocessed the dataset for meaningful visualizations.
- Created line plots, bar charts, and extracted regional insights on unemployment and labor force participation rates.

📌 **Key Tools**: Pandas, Matplotlib, Seaborn  
---

### 📧 Task 3: **Email Spam Classifier**
- Built a machine learning model to classify emails as **Spam** or **Ham** using NLP techniques.
- Preprocessed text data, applied TF-IDF vectorization, and trained models like Naive Bayes and SVM.
- Evaluated model performance using accuracy, precision, and recall.

📌 **Key Tools**: Scikit-learn, NLTK, Pandas  

---

### 🚗 Task 4: **Car Price Prediction Using Machine Learning**
- Predicted car prices based on features like brand, fuel type, mileage, and transmission.
- Performed EDA, feature engineering, and applied regression algorithms (Linear Regression, Random Forest).
- Achieved high R² score and identified key pricing factors.

📌 **Key Tools**: Scikit-learn, Pandas, Seaborn  

---

### 📈 Task 5 (Final Task): **Sales Prediction Using Advertising Data**
- Developed a regression model to predict product sales based on advertising investments (TV, Radio, Newspaper).
- Analyzed feature impact and evaluated performance using metrics like R² and MAE.
- Derived insights on effective marketing strategies.

📌 **Key Tools**: Scikit-learn, Matplotlib, Pandas  
---

## 🧠 Key Learnings

- End-to-end machine learning pipeline: from data cleaning to model deployment.
- Power of visualization in uncovering trends and insights.
- Real-world application of regression and classification models.
- Strengthened problem-solving and analytical thinking skills.
